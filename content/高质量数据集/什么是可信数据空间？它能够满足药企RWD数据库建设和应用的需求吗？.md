
过去几年，真实世界数据（RWD）和真实世界证据（RWE）正在从“科研工具”逐渐变成药企准入、医学、市场和产品生命周期管理的重要基础设施。

无论是医保谈判、医院准入、临床专家教育，还是产品疗效、安全性、经济性证据建设，药企都越来越需要基于多中心、大样本、长期随访的真实世界数据，持续生成高质量证据。

但一个现实问题也越来越突出：

药企需要真实世界数据，医院掌握真实世界数据，但医疗数据不能简单地“拿出来、拷走、卖给药企”。

医疗数据涉及患者隐私、医院管理责任、伦理审查、数据安全、成果转化和收益分配。传统“数据交付式合作”正在面临越来越高的合规压力。

在这个背景下，“可信数据空间”开始成为医疗数据流通和药企RWD数据库建设中的一个关键概念。

# 什么是可信数据空间？

简单理解，可信数据空间不是一个普通数据库，也不是一个文件传输平台，而是一套让多方主体在可信规则下开展数据协作的基础设施。

它的核心不是“把数据搬出去”，而是让数据在安全、可控、可审计的环境中被使用。

在医疗场景中，可信数据空间可以连接医院、药企、数据交易所、数商、科研机构和监管相关方，通过统一的身份认证、权限控制、用途约束、过程留痕、安全计算和结果审核，实现医疗数据的合规流通与价值转化。

换句话说，可信数据空间解决的不是“谁能拿到数据”，而是：

谁可以在什么授权范围内，基于什么目的，以什么方式使用数据，并且整个过程如何被记录、审核和追责。

这也是它与传统数据库最大的区别。

传统数据库更强调“数据集中存储”；可信数据空间更强调“数据在可信规则下可用、可控、可管”。

# 为什么药企建设RWD数据库需要可信数据空间？

药企建设RWD数据库，核心目标不是简单收集数据，而是形成可持续产生证据的能力。

例如，药企可能需要基于RWD完成以下工作：

- 产品疗效与安全性评价；
    

- 真实世界人群特征分析；
    

- 优势患者人群识别；
    

- 医保准入和卫生经济学证据生成；
    

- DRG/DIP支付影响分析；
    

- 临床路径优化研究；
    

- 预测模型开发与外部验证；
    

- 产品上市后真实世界证据补充；
    

- 多中心专家科研合作与论文发表。
    

这些需求都离不开医院真实世界数据。

但医疗数据具有高度敏感性。电子病历、检验检查结果、用药记录、诊断信息、随访资料等，都可能涉及个人信息甚至敏感个人信息。即使经过脱敏，也仍然需要评估重识别风险、明确使用目的、限定授权范围，并完成必要的伦理和院内审批流程。

因此，药企如果仍然沿用过去“把数据脱敏后交给企业”的模式，容易面临几个问题：

1. 医院担心数据出域后不可控；
    
2. 药企难以证明数据使用没有超范围；
    
3. 多中心数据标准不统一，难以持续更新；
    
4. 合作成果难以形成清晰的权属和收益分配；
    
5. 未来用于监管、准入或学术推广时，证据链不够完整。
    

可信数据空间的价值，正是在于为这些问题提供一个新的解决框架。


# 可信数据空间能为药企RWD数据库建设解决什么？

解决“数据不出域”的安全问题

医疗数据合作最大的底线，是不能把原始医疗数据变成不可控流转的资产。

可信数据空间可以通过沙箱、TEE、隐私计算、联邦学习、安全多方计算等方式，实现“数据可用不可见”。

也就是说，药企并不一定直接获得原始数据，而是在授权范围内进行统计分析、模型训练、队列筛选或结果验证。

数据可以留在医院、区域平台或受控环境中，药企获得的是经过审核的计算结果、分析报告、模型参数、数据产品或研究结论。

这大大降低了原始数据复制、外泄、滥用和超范围使用的风险。

  

  

解决多中心RWD协作问题

单中心数据往往存在样本量不足、代表性有限、外推性不强的问题。

药企真正需要的是多中心、跨区域、可持续更新的RWD数据库。

可信数据空间可以在统一规则下连接多家医院，让不同医院的数据在不直接汇聚原始数据的情况下，参与同一项真实世界研究或模型验证。

例如，药企可以围绕某个产品、适应症或临床问题，联合多家医院建设专病队列，完成数据标准化、变量映射、结局定义、模型开发和外部验证。

这使RWD数据库从“一次性数据包”转向“持续更新的数据协作网络”。

  

  

解决过程可审计问题

对于药企而言，RWD证据未来不仅要回答“数据支持什么结论”，还要回答“数据是怎么来的、怎么治理的、谁授权的、怎么使用的、有没有超范围”。

可信数据空间可以记录数据使用全过程，包括主体身份、授权范围、调用数据、运行算法、分析过程、结果导出、审批记录等。

这对于药企非常关键。

因为无论是面对医院、专家、医保、监管还是内部合规部门，药企都需要证明：

- 数据来源合法；
    

- 使用目的明确；
    

- 处理过程合规；
    

- 分析结果可追溯；
    

- 合作流程可审计。
    

可信数据空间让RWD数据库不只是“有数据”，而是具备完整的合规证据链。

  

  

解决持续更新问题

传统数据合作往往是项目制、一次性交付。

项目结束后，数据库也就停止更新。随着诊疗路径、用药方案、医保支付政策和患者结构变化，旧数据很快会失去时效性。

而可信数据空间更适合支持持续型RWD合作。

医院持续沉淀数据，药企根据不同产品和研究问题，在授权范围内调用和分析数据。不同项目之间可以复用治理标准、数据模型和合作机制。

这让RWD数据库从“静态资产”变成“动态证据平台”。

  

  

解决医院参与动力问题

医院不是简单的数据提供方，而是医疗数据成果的形成者、治理者和转化主体。

如果药企只是购买数据，医院的积极性和合规性都难以保障。

更合理的方式，是将经过治理、脱敏、标准化、结构化和实质性加工后的医疗数据，形成数据产品、数据知识产权、专病数据库、预测模型、知识图谱或分析报告，再通过成果转化或数据交易方式开展合作。

在这个过程中，医院可以获得科研成果、论文产出、课题基础、数据资产沉淀和转化收益；专家可以围绕真实临床问题开展高质量研究；药企则获得合规、稳定、可持续的RWD证据来源。

这才是真正的三赢合作

# 可信数据空间能否完全满足药企RWD数据库需求？

答案是：不能完全替代，但可以成为关键底座。

可信数据空间解决的是“数据如何安全、可信、可控地被使用”的问题。

但药企真正建设高质量RWD数据库，还需要叠加五项能力。

  

  

专病队列设计能力

药企必须明确数据库建设目标。

是为了支持医保谈判？医院准入？上市后安全性研究？真实世界疗效评价？卫生经济学分析？还是优势人群识别？

不同目标决定不同的入排标准、变量体系、结局指标和统计方法。

没有清晰研究设计，可信数据空间也只是一个安全环境，不能自动生成高质量证据。

  

  

数据治理能力

医院真实世界数据并不天然等于高质量RWD。

现实中，临床数据常常存在字段缺失、编码不统一、诊断标准不一致、结局记录不完整、随访不足、检验单位不统一等问题。

因此，必须对数据进行标准化、结构化、质控、变量映射和缺失值处理。

可信数据空间可以保障数据使用安全，但不能自动把低质量数据变成高质量数据。

  

  

伦理与合规能力

真实世界研究通常仍然需要伦理审查、知情同意或免知情同意论证、数据安全评估、脱敏匿名化说明、重识别风险评估和院内审批。

可信数据空间不能替代伦理审查，也不能绕过医院内部管理流程。

它是合规使用环境，不是合规豁免工具。

  

  

统计和RWE方法学能力

RWD最大的挑战之一，是偏倚和混杂因素控制。

药企需要通过合理的研究设计和统计方法，提升真实世界证据的可信度。

例如倾向评分匹配、逆概率加权、敏感性分析、亚组分析、竞争风险模型、时间依赖变量处理等，都是高质量RWE研究中常见的方法学工具。

没有方法学支撑，RWD数据库很容易停留在“描述性统计”，难以真正服务产品价值证明。

  

  

成果转化和交易设计能力

医疗数据合作不能停留在技术层面，还必须回答几个商业和合规问题：

- 数据产品的权属如何确认？
    

- 医院和专家如何获得合理收益？
    

- 药企获得的是独家许可还是非独家许可？
    

- 数据产品如何定价？
    

- 是否通过数据交易所挂牌？
    

- 是否形成数据知识产权登记？
    

- 收益如何入账？
    

- 合作期限如何约定？
    

这些问题不解决，RWD数据库建设很难规模化、持续化。

# 药企最适合采用什么路径？

对于药企而言，未来建设RWD数据库，更适合采用一种组合路径：

数据知识产权成果转化 + 数据交易所场内交易 + 可信数据空间交付 + RWE证据生成。

具体来说，可以分为五步。

1. 第一步，药企提出数据需求。  
    围绕产品、适应症、临床场景和证据目标，明确需要建设什么样的RWD数据库。例如疗效评价数据库、安全性数据库、卫生经济学数据库、优势人群识别数据库或预测模型验证数据库。
    
2. 第二步，医院和专家形成数据成果。  
    医院在伦理和院内审批基础上，由临床专家牵头，联合数商或科研服务机构，对院内数据进行治理、脱敏、标准化和实质性加工，形成专病数据集、模型参数、知识图谱、分析报告或数据产品。
    
3. 第三步，完成数据知识产权登记或成果确认。  
    将已经形成的数据产品或数据成果，通过数据知识产权登记、科技成果转化认定、院内成果管理等方式，明确成果属性、权属边界和转化基础。
    
4. 第四步，通过数据交易所或成果转化方式合作。  
    药企不是直接购买原始数据，而是通过授权许可、联合开发、成果转化或场内交易方式，获得特定用途、特定期限、特定范围内的数据产品使用权。
    
5. 第五步，在可信数据空间内完成应用和交付。
    

数据不必直接出院。药企可以在可信数据空间内完成统计分析、模型训练、结果验证和证据生成，最终导出经过审核的研究结果、分析报告、模型参数或RWE证据包。

这一路径的关键，不是“绕开监管”，而是把数据合作从灰色的数据交付，升级为有规则、有权属、有合同、有场景、有审计、有收益分配的成果转化合作。
